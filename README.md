# 🌦️ Weather App

## 📌 Project Description

The **Weather App** is a modern and responsive web application developed using React JS. The main purpose of this project is to provide users with weather information through a simple, attractive, and user-friendly interface.

This application allows users to search for weather details, view temperature, humidity, wind speed, and other weather-related information. It also includes a separate forecast page that users can access through the navigation bar.

The project uses a clean design with blue, white, and orange colors, animated elements, and responsive layouts to improve the user experience.

## 🎯 Objectives

* To develop a responsive weather application using React JS.
* To provide weather information in an easy-to-understand format.
* To implement navigation between the home page and forecast page.
* To practice React components and state management.
* To create an attractive user interface with animations.
* To improve frontend development skills.

## 🚀 Key Features

### 1. Home Page

The home page provides an attractive introduction to the Weather App. It includes a navigation bar, weather search section, and weather information cards.

### 2. Navigation Bar

The navigation bar helps users move between different sections of the application. It includes a blue-colored design and a Forecast option.

### 3. Weather Search

Users can search for weather information by entering a city name.

### 4. Weather Information

The application displays weather-related information, such as:

* Temperature
* Humidity
* Wind Speed
* Visibility
* Weather Conditions

### 5. Forecast Page

When users click the **Forecast** option, they can navigate to a separate forecast page. This page is designed to display weather forecast information with animated elements and attractive styling.

### 6. Animated User Interface

The application includes animations and modern card designs to make the interface visually appealing and engaging.

### 7. Responsive Design

The application is designed to work across different screen sizes, including laptops, desktops, tablets, and mobile devices.

## ⚙️ Working of the Project

1. The user opens the Weather App.
2. The home page displays the navigation bar and weather interface.
3. The user searches for a city to check weather information.
4. The application displays weather details through information cards.
5. The user clicks the Forecast option in the navigation bar.
6. The application navigates to the forecast page.
7. The forecast page displays weather information using an attractive animated interface.
